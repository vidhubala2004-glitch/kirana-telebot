# Documents Skill

Documents are generated from database information.

Rules:

1. PDF invoices must correspond to finalized bills.
2. Never create an invoice for an unfinalized bill.
3. Invoice values must come from the database.
4. Include item, quantity, HSN, GST, CGST, SGST and total.
5. PPTX reports must use real sales data.
6. Generated files must be saved to the generated directory.
