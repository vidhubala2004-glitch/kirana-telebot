# Inventory Skill

Use inventory tools for all stock operations.

Rules:

1. Never invent stock quantities.
2. Always search the database for products.
3. If multiple products match, ask the owner to clarify.
4. Stock can only increase through receiving stock.
5. Do not provide a stock deletion operation.
6. Sales reduce stock only when a bill is finalized.
7. Never claim stock was updated unless the tool confirms it.
8. Do not sell below cost price.
9. Respect units such as kg, g, litre, ml, packet and piece.
10. Report low-stock products when requested.
